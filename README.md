## Cool projects
Check out what I work(ed) on (Full list [here](https://schniepp.dev/builds/)):
- Earsense: ear-training app for self-learners. TypeScript monorepo with a Svelte 5 SPA and a Go API on PostgreSQL, Terraform on Hetzner Cloud, self-hosted Keycloak, dev/staging/prod CI/CD (in development)
- [vuln-tracker](https://github.com/julian-schn/vuln-tracker): CVE dashboard that pulls from the NVD API every two hours, enriches with EPSS and CISA KEV, and ranks by a composite risk score. Python, GitHub Actions, zero-JS static site on GitHub Pages
- Offline Live Translator: fully offline German ⇄ Norwegian live translation for events. NLLB-200 via CTranslate2, semantic search with BGE-M3 in Qdrant, SvelteKit, Docker Compose
- Car Detailing ERP: bespoke ERP that replaces a paper-based workflow for a car detailing business. Go on AWS Lambda, Supabase, CloudFront/S3, staging and prod stacks, OpenAPI 3.1 and ops runbooks
- [dubtitler](https://github.com/julian-schn/dubtitler): agent-powered pipeline that turns a recording into subtitles and a dub in another language, with human review gates for transcript and translation. Python, Claude API
- [cvgen](https://github.com/julian-schn/cvgen): write your CV once in YAML, render it with Typst in multiple languages and layouts
- [Taskflow](https://github.com/julian-schn/taskflow-backend/): todo app on AWS with Lambda and DynamoDB, Java Spring Boot, JWT, React, Docker. Read the blog article with our learnings [here](https://blog.mi.hdm-stuttgart.de/index.php/2025/09/14/springboot-zu-serverless-probleme-und-paradigmen/)!
- [Voice Assistant](https://github.com/julian-schn/113457a-speech_interaction/blob/main/Dokumentation%20Speech%20Interaction.md): offline voice assistant on Raspberry Pi with custom-trained openWakeWord models, Whisper and Piper. See also the [synthetic sample generator](https://github.com/julian-schn/synthetic-positive-wakeword-generator) and [training notebooks](https://github.com/julian-schn/wakeword-howdoyouwanndothis)
- lecture2cards: German lecture PDFs to Markdown notes and Anki flashcards, running fully local on an M2 Mac
- [Blog post about Open-Source AI for Enterprise](https://blog.mi.hdm-stuttgart.de/index.php/2025/07/25/open-source-ai-models-opportunities-and-challenges-for-enterprises/) I wrote for my university's computer science blog
